### Glad to see you here!

I'm a **22-year-old Software Engineer** based in Colombo, Sri Lanka 🇱🇰. I hold a **BEng (Hons) in Software Engineering** from IIT, affiliated with the University of Westminster. I'm currently working as an **Associate Software Engineer at AMDT School of Creativity**, building a University LMS and a banking system for Standard Chartered Bank using Angular and .NET.

Previously, I was a **Trainee Software Engineer at Dialog Axiata – Ideamart**, where I developed scalable RESTful APIs with Spring Boot, built OTP authentication systems, and contributed to an API marketplace used by thousands. I thrive in Agile environments and love automating everything—from CI/CD pipelines to morning standups *(yes, really!)*.
